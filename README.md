# Population Genomics Workflow

A modular whole-genome resequencing workflow for population-genomics analysis in non-model species.

## Workflow

```text
Paired-end FASTQ
      |
      +--> BWA-MEM alignment
      +--> BAM sorting / duplicate handling
      |
      +--> GATK HaplotypeCaller --> per-sample GVCF --> joint genotyping ----+
      |                                                                    |
      +--> SAMtools/bcftools-style multi-sample calling -------------------+
                                                                           |
                                                                           v
                                                             concordant callset
                                                                           |
                                                                           v
                                                                    SNP filtering
                                                                           |
               +------------------+-------------------+---------------------+------------------+
               |                  |                   |                     |                  |
               v                  v                   v                     v                  v
        PCA / ADMIXTURE       phylogeny            LD decay       pi / Fst / Tajima's D     XP-CLR
                                                                          / ROD
               |                                                                  |
               +---------------------------+--------------------------------------+
                                           v
                                  candidate-region genes

Per-sample BAM --> PSMC (optional)
```

The two variant-calling routes are normalized to a consistent VCF representation, and variants present in both callsets are retained for downstream analysis.

## Inputs

- Paired-end short-read FASTQ files
- Reference genome FASTA
- Sample sheet with sample IDs and FASTQ paths
- Sample-to-population table
- GFF/GFF3 annotation
- Chromosome/scaffold list for XP-CLR

## Configuration

```bash
cp config/config.example.sh config/config.sh
cp config/samples.example.tsv config/samples.tsv
cp config/populations.example.tsv config/populations.tsv
cp config/chromosomes.example.txt config/chromosomes.txt
```

Edit paths and dataset-specific parameters before running.

## Variant calling

```bash
bash scripts/00_prepare_reference.sh config/config.sh
bash scripts/01_align_reads.sh config/config.sh
bash scripts/02_gatk_gvcf.sh config/config.sh
bash scripts/03_joint_genotyping.sh config/config.sh
bash scripts/04_samtools_bcftools_call.sh config/config.sh
bash scripts/05_intersect_callsets.sh config/config.sh
bash scripts/06_filter_variants.sh config/config.sh
```

`05_intersect_callsets.sh` normalizes both VCFs and retains variants present in both callsets.

## Population-genomics analyses

```bash
bash scripts/07_population_structure.sh config/config.sh
bash scripts/08_phylogeny.sh config/config.sh
bash scripts/09_ld_decay.sh config/config.sh
bash scripts/10_diversity_selection.sh config/config.sh
```

Pairwise XP-CLR:

```bash
POP_A=POP_A POP_B=POP_B bash scripts/11_xpclr.sh config/config.sh
```

Candidate-region genes:

```bash
SELECTED_BED=/path/to/selected_regions.bed \
  bash scripts/12_candidate_regions.sh config/config.sh
```

PSMC:

```bash
BAM=/path/to/sample.bam SAMPLE=sample01 \
  bash scripts/13_psmc.sh config/config.sh
```

## Plotting

All major visualizations are generated by plotting utilities included in this repository.

Install Python dependencies:

```bash
python -m pip install -r requirements.txt
```

### PCA

```bash
python scripts/14_plot_pca.py \
  --eigenvec /path/to/plink_pca.eigenvec \
  --eigenval /path/to/plink_pca.eigenval \
  --groups config/populations.tsv \
  --output pca.png
```

### ADMIXTURE

```bash
python scripts/15_plot_admixture.py \
  --q /path/to/admixture.3.Q \
  --fam /path/to/admixture.fam \
  --groups config/populations.tsv \
  --output admixture.K3.png
```

### Genome scans

The same utility can plot window-based statistics such as Fst, nucleotide diversity, Tajima's D, ROD, and XP-CLR.

```bash
python scripts/16_plot_genome_scan.py \
  --input /path/to/Fst.POP_A.POP_B.windowed.weir.fst \
  --chrom-col CHROM \
  --pos-col BIN_START \
  --value-col WEIGHTED_FST \
  --ylabel Fst \
  --quantile 0.99 \
  --output fst.png
```

### Joint Fst + pi selection scan

```bash
python scripts/17_plot_fst_pi_selection.py \
  --fst /path/to/Fst.POP_A.POP_B.windowed.weir.fst \
  --pi-a /path/to/pi.POP_A.windowed.pi \
  --pi-b /path/to/pi.POP_B.windowed.pi \
  --name-a POP_A --name-b POP_B \
  --cutoff 0.01 \
  --output fst_pi.POP_A.POP_B.png \
  --selected-output fst_pi.POP_A.POP_B.selected.tsv
```

### LD decay

```bash
python scripts/18_plot_ld_decay.py \
  --inputs /path/to/POP_A.stat.gz /path/to/POP_B.stat.gz \
  --labels POP_A POP_B \
  --output ld_decay.png
```

### Phylogeny

```bash
python scripts/19_plot_phylogeny.py \
  --tree /path/to/cohort_iqtree.treefile \
  --groups config/populations.tsv \
  --output phylogeny.png
```

### PSMC

```bash
python scripts/20_plot_psmc.py \
  --psmc /path/to/sample.combined.psmc \
  --mutation-rate <mutation_rate> \
  --generation-time <generation_time> \
  --output psmc.png
```
